# NFT Marketplace

A full-stack NFT marketplace built using Next.js and Polygon.

## Description

This repository contains the code for a full-stack NFT marketplace built using Next.js, a popular React framework, and Polygon, a layer 2 scaling solution for Ethereum. Users can mint, buy, and sell NFTs (Non-Fungible Tokens) on this platform.

## Features

- User authentication
- Minting NFTs
- Listing NFTs for sale
- Buying NFTs
- Transferring NFTs
- Responsive design

## Technology Stack

- **Frontend**: Next.js, React
- **Smart Contracts**: Solidity
- **Blockchain**: Polygon
- **Backend**: Node.js, Express.js
- **Database**: MongoDB

## Prerequisites

- Node.js
- MongoDB
- Metamask wallet
- Polygon testnet Matic

1. Compile the smart contracts

truffle compile

2. Deploy the smart contracts to the Polygon testnet
truffle migrate --network matic
